## Segnalazione di una vulnerabilità

**Non aprire issue pubbliche per vulnerabilità di sicurezza.**

Inviare il report dettagliato a **alberto.abate@gmail.com** indicando:
- Componente o file interessato
- Descrizione dell'impatto di sicurezza
- Passi dettagliati per la riproduzione o proof of concept

Conferma di ricezione entro 7 giorni. La risoluzione verrà gestita secondo le prassi di responsabile disclosure dell'ecosistema C64-Intelligence-SDK.
