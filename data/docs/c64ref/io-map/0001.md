# $0001 — MOS 6510 Micro-Processor On-Chip I/O Port ($0001)

## Panoramica
Il registro o area di memoria $0001 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0001` (`1` decimale)
- **Range**: `$0001`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### C64 Programmer's Reference Guide (Commodore)
0    /LORAM Signal (0=Switch BASIC ROM Out)
1    /HIRAM Signal (0=Switch Kernal ROM Out)
2    /CHAREN Signal (0=Switch Char. ROM In)
3    Cassette Data Output Line
4    Cassette Switch Sense: 1 = Switch Closed
5    Cassette Motor Control 0 = ON, 1 = OFF
6-7  Undefined
