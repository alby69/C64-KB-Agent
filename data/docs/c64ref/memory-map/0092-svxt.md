# SVXT — Timing constant for tape ($0092)

## Panoramica
Il registro o area di memoria SVXT è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0092` (`146` decimale)
- **Range**: `$0092`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Cassette: temp used to adjust software servo

### Commodore-64-intern-Buch (Commodore)
Dieses Register hat die Aufgabe, kleine
Unterschiede bei der Aufnahmegeschwindigkeit

### C64 Programmer's Reference Guide (Commodore)
Timing Constant for Tape

### Memory Map (Jim Butterfield)
Timing constant for tape

### Mapping the Commodore 64 (Sheldon Leemon)
This location is used as an adjustable timing constant for tape reads,
which can be changed to allow for the slight speed variation between
tapes.

### Reference (Joe Forster / STA)
Unknown. (Timing constant during datasette input.)

### 64'er Magazin (64'er)
Die Speicherzelle enthält eine vom Betriebssystem einstellbare Zahl, welche die
kleinen Unterschiede in der Aufnahmegeschwindigkeit ausgleicht, die bei
verschiedenen Datasetten vorkommen können.

Diese Zeitkonstante steht im Zusammenhang mit der Zahl, die in den
Speicherzellen 176 und 177 steht.

Eine Veränderung der Konstante in Basic ist nicht möglich.
