# $03FC — Freie Speicherplätze ($03FC)

## Panoramica
Il registro o area di memoria $03FC è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$03FC` (`1020` decimale)
- **Range**: `$03FC`-`$03FF`
- **Dimensione**: `4 byte`
- **Permessi**: `R/W`
