# KIKA26 — CIA 1 Interrupt Log ($02A3)

## Panoramica
Il registro o area di memoria KIKA26 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$02A3` (`675` decimale)
- **Range**: `$02A3`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Cassette: holds old D1ICR after clear on read

### Commodore-64-intern-Buch (Commodore)
Bei Bandroutinen wird in dieser
Speicherzelle festgelegt, welche IRQs
freigegeben sind und welche nicht.

### C64 Programmer's Reference Guide (Commodore)
Temp Storage For Cassette Read

### Memory Map (Jim Butterfield)
CIA 1 Interrupt Log

### Mapping the Commodore 64 (Sheldon Leemon)
Save Area for CIA #1 Interrupt Control Register During Cassette Read

### Reference (Joe Forster / STA)
Unknown

### 64'er Magazin (64'er)
Ein weiteres Register (Adresse 56333 beziehungsweise $DC0D) ist für die
Unterbrechungen (Interrupt) des Computers bei Ein- und Ausgaben zuständig.

In der Speicherzelle 675 werden Werte dieses Interruptregisters beim Lesen von
der Kassette zwischengespeichert.

### 64map (—)
Temporary storage during Tape READ
