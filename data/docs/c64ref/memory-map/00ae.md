# $00AE — Tape end adds/End of program ($00AE)

## Panoramica
Il registro o area di memoria $00AE è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$00AE` (`174` decimale)
- **Range**: `$00AE`-`$00AF`
- **Dimensione**: `2 byte`
- **Permessi**: `R/W`

### Commodore-64-intern-Buch (Commodore)
Ähnlich wie $00AC-$00AD funktionieren
diese beiden Speicherzellen. Sie
Zeigen immer auf das Byte, das gerade
gelesen oder gespeichert wurde.

### Mapping the Commodore 64 (Sheldon Leemon)
This location is set by the Kernal routine SAVE to point to the ending
address for SAVE, LOAD, or VERIFY.

### Reference (Joe Forster / STA)
Load address read from input file and pointer to current byte during LOAD/VERIFY from serial bus. End address after LOAD/VERIFY from serial bus or datasette. End address for SAVE to serial bus or datasette. Pointer to line in Color RAM to be scrolled during scrolling the screen

### 64'er Magazin (64'er)
Dieser Zeiger ist der Zwilling zu 172 und 173, nur zeigt er seinerseits auf die
letzte Adresse des zu bewegenden Programms.
