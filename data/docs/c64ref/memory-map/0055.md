# $0055 — Sprungvektor für Funktionen ($0055)

## Panoramica
Il registro o area di memoria $0055 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0055` (`85` decimale)
- **Range**: `$0055`-`$0056`
- **Dimensione**: `2 byte`
- **Permessi**: `R/W`
