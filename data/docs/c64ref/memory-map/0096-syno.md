# SYNO — Tape EOT received ($0096)

## Panoramica
Il registro o area di memoria SYNO è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0096` (`150` decimale)
- **Range**: `$0096`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Cassette: flags if we have block SYNC (16 zero dipoles)

### Commodore-64-intern-Buch (Commodore)
In $0096 werden die Daten
zwischengespeichert, die vom Band
gelesen werden.

### C64 Programmer's Reference Guide (Commodore)
Cassette Sync No

### Memory Map (Jim Butterfield)
Tape EOT received

### Mapping the Commodore 64 (Sheldon Leemon)
Cassette Block Synchronization Number

### Reference (Joe Forster / STA)
Unknown. (End of tape indicator during datasette input/output.)

### 64'er Magazin (64'er)
Diese Speicherzelle wird zur Zwischenspeicherung von Daten beim Lesen einer
Kassette benutzt.

### 64map (—)
Cassette Sync. number
