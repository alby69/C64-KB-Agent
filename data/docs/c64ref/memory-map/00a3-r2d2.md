# R2D2 — Serial bit count/EOI flag ($00A3)

## Panoramica
Il registro o area di memoria R2D2 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$00A3` (`163` decimale)
- **Range**: `$00A3`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

Bits:

* Bit #7: 0 = Send byte right after handshake; 1 = Do EOI delay first.

für alle möglichen Werte benutzt.
