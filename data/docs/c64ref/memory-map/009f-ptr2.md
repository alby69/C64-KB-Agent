# PTR2 — Tp Pass 2 err log corrected ($009F)

## Panoramica
Il registro o area di memoria PTR2 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$009F` (`159` decimale)
- **Range**: `$009F`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Cassette: count of re-read locations (pointer into bad, during re-read)

### Original Source Comments (Microsoft/Commodore)
Temporary 2

### Commodore-64-intern-Buch (Commodore)
Hier werden die Fehler korrigiert,
die bei Kassettenoperationen aufgetreten
sind.

### C64 Programmer's Reference Guide (Commodore)
Tape Pass 2 Error Log

### Memory Map (Jim Butterfield)
Tp Pass 2 err log corrected

### Mapping the Commodore 64 (Sheldon Leemon)
This location is used in correcting bytes of tape data which were
transmitted incorrectly on the first pass.

### Reference (Joe Forster / STA)
Values: $00-$3E, 0-62.

### Reference (Joe Forster / STA)
Auxiliary counter for writing file name into datasette buffer. Auxiliary counter for comparing requested file name with file name read from datasette during datasette input

### 64map (—)
Tape Error log pass 2
