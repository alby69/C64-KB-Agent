# FAT — Device # table ($0263)

## Panoramica
Il registro o area di memoria FAT è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0263` (`611` decimale)
- **Range**: `$0263`-`$026C`
- **Dimensione**: `10 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

Primary device numbers

### Commodore-64-intern-Buch (Commodore)
Diese Tabelle entspricht $0259-$0262,
nur mit dem Unterschied, daß hier die
Geräteadressen vermerkt werden.
