# PTR1 — Tp Pass 1 error log/char buffer ($009E)

## Panoramica
Il registro o area di memoria PTR1 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$009E` (`158` decimale)
- **Range**: `$009E`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Cassette: count of read locations in error (pointer into bad, max 61)

### Original Source Comments (Microsoft/Commodore)
Temporary 1

### Commodore-64-intern-Buch (Commodore)
Diese Speicherzelle wird zur
Überprüfung von Bytes bei Kassettenoperationen
benutzt.

### C64 Programmer's Reference Guide (Commodore)
Tape Pass 1 Error Log

### Memory Map (Jim Butterfield)
Tp Pass 1 error log/char buffer

### Mapping the Commodore 64 (Sheldon Leemon)
This location is used in setting up an error log of bytes in which
transmission parity errors occur the first time that the block is
received (each tape block is sent twice to minimize data loss from
transmission error).

### Reference (Joe Forster / STA)
Values: $00-$3E, 0-62.

### Reference (Joe Forster / STA)
Block header type during datasette input/output. Length of file name during datasette input/output. Byte to be put into output buffer during RS232 and datasette output

### 64'er Magazin (64'er)
Diese beiden Speicherzellen werden von Routinen des Betriebssystems verwendet,
welche bei Kassettenoperationen die Zeichen überprüfen, ob sie richtig sind,
und welche bei aufgetretenen Fehlern Korrekturen durchführen.

### 64map (—)
Tape Error log pass 1

### 64map (—)
Index to Cassette File name/Header ID for Tape write
