# $0057 — Misc numeric work area ($0057)

## Panoramica
Il registro o area di memoria $0057 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0057` (`87` decimale)
- **Range**: `$0057`-`$0060`
- **Dimensione**: `10 byte`
- **Permessi**: `R/W`
