# $00FB — unbenutzt ($00FB)

## Panoramica
Il registro o area di memoria $00FB è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$00FB` (`251` decimale)
- **Range**: `$00FB`-`$00FE`
- **Dimensione**: `4 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Free KERNAL zero page 9/24/80

### Commodore-64-intern-Buch (Commodore)
unbenutzt

### C64 Programmer's Reference Guide (Commodore)
Free 0-Page Space for User Programs

### Mapping the Commodore 64 (Sheldon Leemon)
These locations were specifically set aside for user-written ML
routines that require zero-page addressing.  While other zero-page
locations can be used on a noninterference basis, it is guaranteed
that BASIC will not alter these locations.

### Reference (Joe Forster / STA)
Unused (4 bytes)

### 64'er Magazin (64'er)
Diese 4 Byte sind frei, und da sie von Basic nicht gestört beziehungsweise
verändert werden, eignen sie sich in idealer Weise für Flaggen, Register oder
andere Zwischenspeicher.

### 64map (—)
Free Zero Page space for User Programs
