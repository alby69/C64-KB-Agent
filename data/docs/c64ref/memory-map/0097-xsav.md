# XSAV — Register save ($0097)

## Panoramica
Il registro o area di memoria XSAV è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0097` (`151` decimale)
- **Range**: `$0097`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
Temp for BASIN

### Commodore-64-intern-Buch (Commodore)
Beim Lesen von Band wird hier das
X-Register zwischengespeichert.

### C64 Programmer's Reference Guide (Commodore)
Temp Data Area

### Memory Map (Jim Butterfield)
Register save

### Mapping the Commodore 64 (Sheldon Leemon)
This .X register save area is used by the routines that get and put an
ASCII character.

### Reference (Joe Forster / STA)
Temporary area for saving original value of Y register during input from RS232. Temporary area for saving original value of X register during input from datasette

### 64'er Magazin (64'er)
Maschinen-Programmierer kennen das X-Register des Mikroprozessors. Beim Lesen
eines Zeichens von der Datasette wird der Inhalt des X-Registers in dieser
Adresse zwischengespeichert.

### 64map (—)
Temporary storage of X Register during CHRIN. Temporary storage of Y Register during RS232 fetch
