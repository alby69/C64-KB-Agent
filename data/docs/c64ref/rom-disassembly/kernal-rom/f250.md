# $F250 — ;

## Disassemblatura
```assembly
.F250  20 0F F3 JSR $F30F   ; NCKOUT JSR LOOKUP      ;IS FILE IN TABLE?
.F253  F0 03    BEQ $F258   ; BEQ    CK5             ;YES... ;
.F255  4C 01 F7 JMP $F701   ; JMP    ERROR3          ;NO...FILE NOT OPEN ;
.F258  20 1F F3 JSR $F31F   ; CK5    JSR JZ100       ;EXTRACT TABLE INFO ;
.F25B  A5 BA    LDA $BA   ; LDA    FA              ;IS IT KEYBOARD?
.F25D  D0 03    BNE $F262   ; BNE    CK10            ;NO...SOMETHING ELSE. ;
.F25F  4C 0D F7 JMP $F70D   ; CK20   JMP ERROR7      ;YES...NOT OUTPUT FILE ; ;COULD BE SCREEN,SERIAL,OR TAPES ;
.F262  C9 03    CMP #$03   ; CK10   CMP #3
.F264  F0 0F    BEQ $F275   ; BEQ    CK30            ;IS SCREEN...DONE
.F266  B0 11    BCS $F279   ; BCS    CK40            ;IS SERIAL...ADDRESS IT
.F268  C9 02    CMP #$02   ; CMP    #2              ;RS232?
.F26A  D0 03    BNE $F26F   ; BNE    CK15 ;
.F26C  4C E1 EF JMP $EFE1   ; JMP    CKO232 ; ; ;SPECIAL TAPE CHANNEL HANDLING ;
.F26F  A6 B9    LDX $B9   ; CK15   LDX SA
.F271  E0 60    CPX #$60   ; CPX    #$60            ;IS COMMAND READ?
.F273  F0 EA    BEQ $F25F   ; BEQ    CK20            ;YES...ERROR ;
.F275  85 9A    STA $9A   ; CK30   STA DFLTO       ;ALL OUTPUT GOES HERE ;
.F277  18       CLC   ; CLC                    ;GOOD EXIT
.F278  60       RTS   ; RTS ;
.F279  AA       TAX   ; CK40   TAX             ;SAVE DEVICE FOR DFLTO
.F27A  20 0C ED JSR $ED0C   ; JSR    LISTN           ;TELL HIM TO LISTEN ;
.F27D  A5 B9    LDA $B9   ; LDA    SA              ;IS THERE A SECOND?
.F27F  10 05    BPL $F286   ; BPL    CK50            ;YES... ;
.F281  20 BE ED JSR $EDBE   ; JSR    SCATN           ;NO...RELEASE LINES
.F284  D0 03    BNE $F289   ; BNE    CK60            ;BRANCH ALWAYS ;
.F286  20 B9 ED JSR $EDB9   ; CK50   JSR SECND       ;SEND SECOND... ;
.F289  8A       TXA   ; CK60   TXA
.F28A  24 90    BIT $90   ; BIT    STATUS          ;DID HE LISTEN?
.F28C  10 E7    BPL $F275   ; BPL    CK30            ;YES...FINISH UP ;
.F28E  4C 07 F7 JMP $F707   ; JMP    ERROR5          ;NO...DEVICE NOT PRESENT .END .LIB   CLOSE
```

### Original Disassembly (—)
- **$F250**: find a file
- **$F253**: if file found continue
- **$F255**: else do 'file not open' error and return
- **$F258**: set file details from table,X
- **$F25B**: get the device number
- **$F25D**: if the device is not the keyboard go ??
- **$F25F**: go do 'not output file' error and return
- **$F262**: compare the device with the screen
- **$F264**: if the device is the screen go save output the output device number and exit
- **$F266**: if > screen then go handle a serial bus device
- **$F268**: compare the device with the RS232 device
- **$F26A**: if not the RS232 device then it must be the tape device
- **$F26C**: else go open RS232 channel for output open a tape channel for output
- **$F26F**: get the secondary address
- **$F273**: if ?? do not output file error and return
- **$F275**: save the output device number
- **$F277**: flag ok
- **$F279**: copy the device number
- **$F27A**: command devices on the serial bus to LISTEN
- **$F27D**: get the secondary address
- **$F27F**: if address to send go ??
- **$F281**: else set serial ATN high
- **$F284**: go ??, branch always
- **$F286**: send secondary address after LISTEN
- **$F289**: copy device number back to A
- **$F28A**: test the serial status byte
- **$F28C**: if the device is present go save the output device number and exit
- **$F28E**: else do 'device not present error' and return

### Commodore-64-intern-Buch (Commodore)
- **$F250**: sucht logische Filenummer
- **$F253**: verzweige wenn gefunden
- **$F255**: sonst 'FILE NOT OPEN'
- **$F258**: setzt Fileparameter
- **$F25B**: Gerätenummer holen
- **$F25D**: verzweige wenn ungleich Null
- **$F25F**: sonst 'NOT INPUT FILE'
- **$F262**: vergleiche mit Bildschirm ?
- **$F264**: verzweige wenn Bildschirm
- **$F266**: verzweige wenn IEC-Bus
- **$F268**: vergleiche mit RS-232
- **$F26A**: verzweige wenn nein
- **$F26C**: Ausgabe auf RS-232 vorbereiten

### Magnus Nyman (Magnus Nyman)
- **$F250**: fine file number (X)
- **$F253**: OK
- **$F255**: I/O error #3, file not open
- **$F258**: set file values
- **$F25B**: FA, current device number
- **$F25D**: not keyboard
- **$F25F**: I/O error #7, not output file
- **$F262**: screen?
- **$F264**: yes
- **$F266**: serial bus device
- **$F268**: RS232
- **$F26A**: nope
- **$F26C**: submit to RS232
- **$F26F**: SA, current secondary address
- **$F273**: not output file error
- **$F275**: DFLTO, default output device
- **$F277**: clear carry to indicate no errors
- **$F279**: file (X) to (A)
- **$F27A**: send LISTEN to serial device
- **$F27D**: SA
- **$F27F**: send SA
- **$F281**: clear ATN
- **$F286**: send listen secondary address
- **$F28A**: STATUS, I/O status word
- **$F28C**: OK, set output device
- **$F28E**: I/O error #5, device not present
