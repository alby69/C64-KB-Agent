# $F333 — ;**

## Disassemblatura
```assembly
.F333  A2 03    LDX #$03   ; NCLRCH LDX #3
.F335  E4 9A    CPX $9A   ; CPX    DFLTO           ;IS OUTPUT CHANNEL IEEE?
.F337  B0 03    BCS $F33C   ; BCS    JX750           ;NO... ;
.F339  20 FE ED JSR $EDFE   ; JSR    UNLSN           ;YES...UNLISTEN IT ;
.F33C  E4 99    CPX $99   ; JX750  CPX DFLTN       ;IS INPUT CHANNEL IEEE?
.F33E  B0 03    BCS $F343   ; BCS    CLALL2          ;NO... ;
.F340  20 EF ED JSR $EDEF   ; JSR    UNTLK           ;YES...UNTALK IT ; ;RESTORE DEFAULT VALUES ; ;
.F343  86 9A    STX $9A   ; CLALL2 STX DFLTO       ;OUTPUT CHAN=3=SCREEN
.F345  A9 00    LDA #$00   ; LDA    #0
.F347  85 99    STA $99   ; STA    DFLTN           ;INPUT CHAN=0=KEYBOARD
.F349  60       RTS   ; RTS .END .LIB   OPEN
```


## Commenti

### Original Disassembly (Commodore)
- **$F333**: NCLRCH LDX #3
- **$F335**: CPX    DFLTO           ;IS OUTPUT CHANNEL IEEE?
- **$F337**: BCS    JX750           ;NO... ;
- **$F339**: JSR    UNLSN           ;YES...UNLISTEN IT ;
- **$F33C**: JX750  CPX DFLTN       ;IS INPUT CHANNEL IEEE?
- **$F33E**: BCS    CLALL2          ;NO... ;
- **$F340**: JSR    UNTLK           ;YES...UNTALK IT ; ;RESTORE DEFAULT VALUES ; ;
- **$F343**: CLALL2 STX DFLTO       ;OUTPUT CHAN=3=SCREEN
- **$F345**: LDA    #0
- **$F347**: STA    DFLTN           ;INPUT CHAN=0=KEYBOARD
- **$F349**: RTS .END .LIB   OPEN

### Original Disassembly (—)
- **$F333**: set the screen device
- **$F335**: compare the screen with the output device number
- **$F337**: if <= screen skip the serial bus unlisten
- **$F339**: else command the serial bus to UNLISTEN
- **$F33C**: compare the screen with the input device number
- **$F33E**: if <= screen skip the serial bus untalk
- **$F340**: else command the serial bus to UNTALK
- **$F343**: save the screen as the output device number
- **$F345**: set the keyboard as the input device
- **$F347**: save the input device number

### Commodore-64-intern-Buch (Commodore)
- **$F333**: Vergleichswert in X
- **$F335**: vergleiche mit Nummer des Ausgabegeräts
- **$F337**: verzweige wenn kleiner als 3
- **$F339**: IEC, UNLISTEN senden
- **$F33C**: vergleiche mit Nummer des Eingabegeräts
- **$F33E**: verzweige wenn kleiner als 3
- **$F340**: IEC, UNTALK senden
- **$F343**: Ausgabe wieder auf Bildschirm
- **$F345**: Eingabe wieder
- **$F347**: von Tastatur
- **$F349**: Rücksprung

### Magnus Nyman (Magnus Nyman)
- **$F333**: check if device > 3 (serial bus is 4,5...)
- **$F335**: test DFLTO, default output device
- **$F337**: nope, no serial device
- **$F339**: send UNLISTEN to serial bus
- **$F33C**: test DFLTI, default input device
- **$F33E**: nope, no serial device
- **$F340**: send UNTALK to serial bus
- **$F343**: store screen as DFLTO
- **$F347**: store keyboard as DFLTI
