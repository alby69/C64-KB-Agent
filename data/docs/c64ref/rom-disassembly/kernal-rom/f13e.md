# $F13E — ;

## Disassemblatura
```assembly
.F13E  A5 99    LDA $99   ; NGETIN LDA DFLTN       ;CHECK DEVICE
.F140  D0 08    BNE $F14A   ; BNE    GN10            ;NOT KEYBOARD ;
.F142  A5 C6    LDA $C6   ; LDA    NDX             ;QUEUE INDEX
.F144  F0 0F    BEQ $F155   ; BEQ    GN20            ;NOBODY THERE...EXIT ;
.F146  78       SEI   ; SEI
.F147  4C B4 E5 JMP $E5B4   ; JMP    LP2             ;GO REMOVE A CHARACTER ;
.F14A  C9 02    CMP #$02   ; GN10   CMP #2          ;IS IT RS-232
.F14C  D0 18    BNE $F166   ; BNE    BN10            ;NO...USE BASIN ;
.F14E  84 97    STY $97   ; GN232  STY XSAV        ;SAVE .Y, USED IN RS232
.F150  20 86 F0 JSR $F086   ; JSR BSI232
.F153  A4 97    LDY $97   ; LDY XSAV        ;RESTORE .Y
.F155  18       CLC   ; GN20   CLC             ;GOOD RETURN
.F156  60       RTS   ; RTS
```


## Commenti

### Original Disassembly (Commodore)
- **$F13E**: NGETIN LDA DFLTN       ;CHECK DEVICE
- **$F140**: BNE    GN10            ;NOT KEYBOARD ;
- **$F142**: LDA    NDX             ;QUEUE INDEX
- **$F144**: BEQ    GN20            ;NOBODY THERE...EXIT ;
- **$F146**: SEI
- **$F147**: JMP    LP2             ;GO REMOVE A CHARACTER ;
- **$F14A**: GN10   CMP #2          ;IS IT RS-232
- **$F14C**: BNE    BN10            ;NO...USE BASIN ;
- **$F14E**: GN232  STY XSAV        ;SAVE .Y, USED IN RS232
- **$F150**: JSR BSI232
- **$F153**: LDY XSAV        ;RESTORE .Y
- **$F155**: GN20   CLC             ;GOOD RETURN
- **$F156**: RTS

### Original Disassembly (—)
- **$F13E**: get the input device number
- **$F140**: if not the keyboard go handle other devices the input device was the keyboard
- **$F142**: get the keyboard buffer index
- **$F144**: if the buffer is empty go flag no byte and return
- **$F146**: disable the interrupts
- **$F147**: get input from the keyboard buffer and return the input device was not the keyboard
- **$F14A**: compare the device with the RS232 device
- **$F14C**: if not the RS232 device go ?? the input device is the RS232 device
- **$F14E**: save Y
- **$F150**: get a byte from RS232 buffer
- **$F153**: restore Y
- **$F155**: flag no error

### Commodore-64-intern-Buch (Commodore)
- **$F13E**: Eingabegerät laden
- **$F140**: verzweige wenn nicht Tastatur
- **$F142**: Anzahl der Zeichen im Tastaturpuffer laden
- **$F144**: verzweige wenn kein Zeichen
- **$F146**: Interruptflag setzen
- **$F147**: Zeichen aus Tastaturpuffer holen
- **$F14A**: Geräteadresse für RS-232
- **$F14C**: nein dann zur BASIN-Routine
- **$F14E**: Y-Register merken
- **$F150**: Get von RS 232
- **$F153**: Y-Register wiederholen
- **$F155**: Carry löschen, ok
- **$F156**: Rücksprung

### Magnus Nyman (Magnus Nyman)
- **$F13E**: DFLTN, default input device.
- **$F140**: not keyboard
- **$F142**: NDX, number of keys in keyboard queue
- **$F144**: buffer empty, exit
- **$F146**: disable interrupts
- **$F147**: get character from keyboard buffer, and exit
- **$F14A**: RS232
- **$F14C**: nope, try next device
- **$F14E**: temp store
- **$F150**: get character from RS232
- **$F153**: retrieve (Y)
