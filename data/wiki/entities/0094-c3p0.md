# Serial output : deferred char flag



# C3P0 — Serial output : deferred char flag ($0094)

## Panoramica
Il registro o area di memoria C3P0 è descritto in dettaglio di seguito.

## Dettagli Tecnici
- **Indirizzo**: `$0094` (`148` decimale)
- **Range**: `$0094`
- **Dimensione**: `1 byte`
- **Permessi**: `R/W`

## Descrizioni per Fonte

### Original Source Comments (Microsoft/Commodore)
IEEE buffered char flag

### Commodore-64-intern-Buch (Commodore)
Diese Adresse setzt bei Floppy und
Drucker den "LISTEN" Zustand.

### C64 Programmer's Reference Guide (Commodore)
Flag: Serial Bus-Output Char. Buffered

### Memory Map (Jim Butterfield)
Serial output : deferred char flag

### Mapping the Commodore 64 (Sheldon Leemon)
This location is used by the serial output routines to indicate that a
character has been placed in the output buffer and is waiting to be
sent.

### Reference (Joe Forster / STA)
Bits:

* Bit #7: 1 = Output cache dirty, must transfer cache contents upon next output to serial bus.

### 64'er Magazin (64'er)
Das Betriebssystem benutzt diese Speicherzelle, um anzuzeigen, daß ein Zeichen
im Ausgabepuffer steht, welches zum Floppy-Gerät oder zum Drucker geleitet
werden soll. Diese Flagge setzt alle am seriellen Port angeschlossenen Geräte
in den Zustand »Listen«, das heißt bereit zu sein, Daten aufzunehmen.

### 64map (—)
Flag: Serial Bus - Output Character buffered
