# $AEA8 — PI as floating number

## Disassemblatura
```assembly
.AEA8  82 49 0F DA A1   ; 3.141592653
```


## Commenti

### Original Disassembly (—)
- **$AEA8**: 3.141592653

### Marko Mäkelä (Marko Mäkelä)
- **$AEAD**: decimal point
- **$AEB1**: plus code
- **$AEB5**: times code
- **$AEB9**: quote mark
- **$AECC**: NOT code
