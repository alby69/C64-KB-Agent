This page provides a copy of the source code to Modplay 128 v1.0. This freeware program is a player for standard Protracker or Noisetracker MOD.* files, for the C128. This program's look/feel was based on Mark Dickenson's Stereo SID Player v10.3, and features a simple playlist editor, loadable drivers, and more.
