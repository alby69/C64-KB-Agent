                # Modplay 64

This page provides a copy of the source code to Modplay 64 v1.2. This program plays a standard 4-voice Protracker or Noisetracker MOD.* file. The program uses a simple menu interface and you select files using patterns, so nothing fancy there, but it also features basic support for the CMD SuperCPU.
