# The 6502 Second Processor demo mode

## All about the Star Wars-esque scroll text in the Tube-based version of Elite

The 6502 Second Processor has a unique demo mode that only appears in this version. It shows off the improved speed of the 3 MHz 65C02 processor that sits at the heart of the famous wedge-shaped expansion box, though as you can't escape from the demo once it has started, it can get a bit annoying for seasoned players. Still, it's a bit of fun, if only for the first few times ...
